# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery

## Project Description

Paradise Nursery is a React-based online plant shopping application.

The application allows users to browse different categories of houseplants,
view plant names and prices, add plants to a shopping cart, update quantities,
remove products, and view the total cost of their cart.

## Features

- Responsive landing page
- Paradise Nursery company branding
- Get Started button
- About Us page
- Plant listing page
- Three plant categories
- At least six plants per category
- Plant thumbnails
- Plant names and prices
- Add to Cart functionality
- Disabled Add to Cart button after adding
- Dynamic cart item counter
- Redux Toolkit shopping cart
- Increase quantity
- Decrease quantity
- Delete cart items
- Total item count
- Total cart amount
- Checkout Coming Soon message
- Continue Shopping button
- Responsive design
